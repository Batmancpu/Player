# Offline browsing and playback preview

Signed preview release: [v0.1.91](https://github.com/Batmancpu/Player/releases/tag/v0.1.91). This adds useful local parts of catalogue and playback before online metadata. It uses only the already selected read-only folder. Titles come from filenames; the coloured cards are local placeholders, not retrieved posters. No network permission, shared API credential or backend is added. Embedded subtitle controls use Media3; sidecar loading, custom track sheets and subtitle delay remain later work.

## Optional phone check when convenient

1. Update through Obtainium without uninstalling. Confirm the existing folder and four movies remain.
2. Search a title or year; clear the search, try Movies/Shows, then open a movie's details.
3. Tap **Play video**. Try pause, seek, Back to library and reopen; check resume. Try airplane mode too.
4. Leave the app during playback. It should pause; return and resume intentionally. Try rotation and unplugging headphones if available.
5. In **Manage**, rescan or choose another folder. Only the chosen folder's titles should appear. No deletion or modification of originals is required.
6. Open **Glass preview** from Manage. Compare effects on/off and tap each dock tab. Report any clipping, disconnected surface or unreadable text when convenient.

Report unsupported files only by container/codec and symptom when known; do not post private filenames, paths, content or tokens. One owned H.264/AAC emulator fixture cannot establish every codec/container or actual OPPO decoder compatibility.

## Automated evidence and limits

CI checks JVM filename/grouping/search behavior; Room reconciliation/rollback; provider cancellation and cursor cleanup; root/permission rejection; content-only first-frame decoding and seek; private resume isolation; synthetic browsing/details/play identity; dock layout/fallback screenshots; actual signed APK identity, permissions/backup and permanent certificate. The generated video/provider/screenshots are test-only synthetic data and excluded from release.

Source compilation and automated evidence do not establish OPPO appearance, 60/120 FPS, thermal behavior or complete phase acceptance. Follow `DESIGN_SYSTEM_AND_PERFORMANCE.md` for release-like physical Macrobenchmark/Perfetto work. Independent development continues while phone evidence is unavailable.
